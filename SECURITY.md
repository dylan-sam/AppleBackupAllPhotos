# Privacy and issue reports

The app copies files locally. It does not upload photos, backups, passwords, or device identifiers. The backup password is used only during the current process and is not written to a project file. Apple pairing data may be stored in the current user's local application data folder so the USB connection can be reused.

Before posting an issue or screenshot, remove device names, identifiers, backup paths, photo filenames, passwords, and any content from personal files. Never attach a backup or pairing record to a public issue.

The app reads from the device and backup. It does not delete source files. An interrupted destination file may remain with a `.partial` extension; a later run replaces it.
